# UI 美化第五轮设计文档

日期: 2026-02-24
分支: `ui/beautify-round5`
风格: 极简科技风 (Linear/Vercel 风格)

## 设计原则

- 绿色唯一强调色 + 黑白灰
- 大留白，去装饰化
- 克制但有层级

## 变更清单

### 1. 配色重构
- 去掉蓝色 `#1677FF` 系列，次级操作全部改为灰色系
- 更新所有 `UI_COLOR_*` 常量为上表值
- Open Image / Save Result 等按钮从蓝色改为灰底+深色文字

### 2. 视觉精细化
- 统一圆角 8px（卡片、按钮、输入框）
- 卡片间距统一 12px
- 卡片标题：保留 bold，颜色改为次级色 `#737373`
- 去掉多余边框装饰，用间距分隔
- 图像区域用极简 1px 边框

### 3. 按钮层级简化
- 主操作 (Start Restoration): 绿底白字，hover `#059669`
- 次级操作 (Batch/Cancel/Open/Save 等): `#F5F5F5` 底 + `#404040` 文字，hover `#EBEBEB`
- 幽灵按钮 (Load GT): transparent + 边框 `#E5E5E5`，hover `#F5F5F5`
- 不做动画循环，hover 只用柔和相近色

### 4. 交互体验
- 进度条：改为细线条风格 (height 4px)，绿色填充
- Tooltip：为关键按钮添加悬浮提示
- 状态栏：简化样式，与整体风格统一

### 5. 整体布局微调
- 侧栏紧凑化：减少内部 padding
- 工具栏按钮扁平化
- 输出占位文字样式统一为提示色

# Claude 配置规则

## 基本规则

- 用中文回复问题
- 每次回复最后加「喵~」
- 调用工具前如需输出占位文字，用「喵~」代替

## Context Files
- 每当有重要变更时，同步更新 `.context/CURRENT_TASK.md` 和 `.context/CHANGELOG.md`。

## 默认简洁模式

- 首次回复控制在 500 字以内
- 只提供核心要点、关键函数列表和文件位置
- 使用清晰的结构化格式（标题、列表、表格）

## 渐进式详细

- 在简洁回复后，主动使用 AskUserQuestion 工具询问："需要我详细介绍或读取哪个部分？"
- 提供 2-4 个可选的深入方向
- 根据用户选择深入特定部分

## 长内容处理策略

- 当预计回复超过 800 字时，先输出概要
- 明确告知用户："这是一个复杂主题，我先给你概要"
- 列出可以深入的具体方面
- 等待用户选择后再继续

## 例外情况

- 用户明确说"详细解释"、"完整输出"、"不要分段"时，可以输出较长内容
- 但仍需在 800 字左右时考虑自然分段点，询问是否继续
- 如果用户说"继续"，则继续输出下一部分

## Git 操作

- "提交"和"上传"均指提交并推送（git commit + git push）
- 未经用户明确允许，不可私自执行 git push
- PR 合并到主分支后，自动删除当前功能分支（本地+远程）并拉取主分支最新代码
